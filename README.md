# The Dynamic Event Guest Book & Tracker

A lightweight front-end web app for managing an event guest list. It allows users to add guest names, automatically track the attendee count, and render the guest list dynamically in the browser.

## Features

- Add guest names from an input field
- Prevent blank or whitespace-only entries
- Update the total number of attendees live
- Render the guest list using generated HTML list items
- Clear the input field after each valid submission

## Project Files

- `index.html` – app structure, styling, and JavaScript logic

## How to Run

1. Open `index.html` in any modern browser.
2. Enter a guest name in the input field.
3. Click the **Add** button.
4. The guest will appear in the list and the total counter will update automatically.

## Notes

- The app is a simple client-side project with no backend required.
- Data is stored in a JavaScript array while the page is open.
- This project is ideal for learning DOM manipulation, array handling, and basic event listeners in JavaScript.
